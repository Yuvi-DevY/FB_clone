# FB_clone 🚀

A modern, responsive, and full-featured **Facebook Clone** built to replicate core social media functionalities. This project demonstrates clean UI design, seamless state management, and real-time interactive features.

---

## 📌 Features

### 🔐 User Experience & Authentication
* **Secure Authentication:** User sign-up, login, and logout functionalities.
* **Profile Management:** Custom user profiles with profile pictures, cover photos, and personal bios.

### 📝 Social Feed & Interactions
* **Dynamic News Feed:** Real-time post updates including text and image uploads.
* **Interactions System:** Instant like/unlike actions and interactive comment sections on posts.
* **Friendship Network:** Add, accept, or remove friends to customize feed visibility.

### ⚡ Performance & Design
* **Responsive Layout:** Pixel-perfect design optimized for mobile, tablet, and desktop screens.
* **Visual Themes:** Toggle seamlessly between clean Light Mode and eye-strain-free Dark Mode.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 / TailwindCSS, JavaScript (ES6+)
* **State Management:** Local State / Context API
* **Version Control:** Git & GitHub

---

## 🚀 Getting Started

Follow these simple steps to get a local copy of the project up and running.

### 1. Prerequisites
Make sure you have Git installed on your local machine.

### 2. Installation & Setup
Clone the repository and navigate into the project directory:

```bash
git clone https://github.com
cd FB_clone
```

### 3. Running Locally
Simply open the `index.html` file in your favorite web browser, or use a local development server like **Live Server** in VS Code for live-reloading.
